# 水懒 Git 官网

静态官网，部署于 GitHub Pages。产品**不开源**；下载只走 [Releases](https://github.com/ShaoAsher/ottergit-site/releases/latest)。

## 本地预览

```bash
cd ottergit-site
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```
