01 · 仓库状态

仓库处在什么状态，
窗口一眼告诉你。

背景环境层的颜色、小獭的表情、状态栏的提示都读同一份仓库状态。往下滚动，本页背景也会跟着变。

  1. 有改动

    改了 12 个文件，先看清再提交

    待提交的文件按目录列出，选中一个，右边就是左右对齐的对比。只想先交其中一处？点改动块上的「暂存此块」。

  2. 合并冲突

    撞上冲突，横幅会一直提醒

    冲突文件排在最前面并标红。只有一边改过的块可以自动解决，两边都改过的逐块挑选，也能打开三方合并对照着改。

  3. 小獭协助

    交给小獭，它先列出步骤

    「帮我写提交说明并提交」：小獭暂存、起草说明，到推送这一步先停下，出一张确认卡，写清会改动什么、风险等级多高。

  4. 已同步

    推送完成，历史里记得清清楚楚

    每个分支一条泳道，本地和远程停在哪一目了然。顶部统计栏记录这个仓库一共提交了多少次、今天提交了几次。

02 · 结果反馈

提交完成，
下一步就在弹窗里。

提交、推送、拉取的进度弹窗在完成后原地切换成结果页，不用再去工具栏找按钮。

  • 提交后一键推送有上游分支时，结果页的主按钮就是「推送」；没有上游时可以直接撤销这次提交。
  • 里程碑会被记住第 1 次、每第 100 次提交，小獭会换上庆祝的表情，记下这一次。
  • 小事不打断你「已是最新」「已暂存」这类结果只在状态栏提示一句，几秒后自动消失。

03 · 小獭 AI 助手 2.0

动手之前，先确认。

小獭在窗口右侧。看状态、拉取、推送、暂存这些短指令不配模型也能用；配上模型后，写提交说明、起草 PR 描述、把「提交并推送」拆成几步完成，都可以交给它。

Steps

每一步都摆出来

多步任务显示为步骤卡：已完成、进行中、待执行一眼分清，思考过程可以展开查看。

Confirm · L1–L3

写操作先出确认卡

确认卡列出涉及的文件、目标分支和领先落后数，并标注风险等级。强制推送、硬重置、丢弃改动每次单独确认。

Memory

会话按仓库隔离

每个仓库有自己的对话记录和仓库记忆，提交约定、分支习惯会自动带上。仓库里有 AGENTS.md 时也会读取。

Model

模型由你自己接入

填写接口地址、API Key 和模型名称，兼容 OpenAI 接口的服务都可以使用。用量按模型记录，随时可查。

01 · 提交历史

按泳道看清分叉

每个分支一条泳道。本地停在哪、远程走到哪、谁合进了谁，图上都标着。点开一条提交，右侧就是这次改了哪些文件。

  • 按提交说明、作者或哈希搜索，⌘3 直接打开
  • 右键提交可以遴选、变基、创建补丁
02 · 逐行对比

删除标红，新增标绿

新旧两栏按行对齐，一边多出几行，另一边就空出几行，后面的代码不会整段错位。一个文件改了三处，可以只暂存其中一处。

  • 暂存文件、暂存此块、丢弃此块，按钮都在改动块的标题栏上
  • 也可以换成外部差异比对工具
03 · 合并冲突

冲突逐块解决

拉取时撞上冲突，冲突文件排在列表最前面。只有一边改过的块点「自动解决」，两边都改过的用「逐块解决」，想看全貌就打开「三方合并」。

  • 合并没完成时，顶部横幅一直提醒，改完点「去提交」
  • 点「中止合并」回到合并前的状态

08 · 常见问题

你可能想问的

要花钱吗？

不用。没有内购、订阅或专业版。小獭使用的模型由你自己接入，费用直接与模型服务商结算，App 不经手。

小獭会擅自改动我的仓库吗？

出厂为「默认」档：日常操作直接执行，拉取、推送等会先确认，不可撤销的操作每次单独确认。也可以调到「询问」或「完全信任」。冲突没解决完的提交，任何一档都会拦下。

我的代码会被上传吗？

仓库读写都在本机完成，使用的是你安装的 git。未配置模型时，小獭的短指令也在本机执行。配置模型并与它对话时，相关内容会发送到你填写的接口地址。

支持 Windows 和 Intel Mac 吗？

Windows 10 / 11（x64）提供预览版，欢迎反馈问题。Intel 芯片的 Mac 暂不支持。

需要先安装 git 吗？

需要。水獭 Git 调用的是本机的 git。装了多个版本时，可以在设置里指定使用哪一个。

官网的在线试用和 App 一样吗？

界面、交互和动效与 App 2.0 一致，用来快速了解操作方式；数据是演示数据，不会读取你的仓库。完整功能请下载 App 使用。

为什么叫水獭？

水獭睡觉时会牵着同伴的手，避免彼此走散。分支一多也容易走散，总得有谁帮你盯着。
